# Personal Portfolio - Oasis Infobyte SIP Task 2

This is a personal portfolio website created as my digital resume for the Oasis Infobyte Web Development Internship (Level 1, Task 2).

## Technologies Used
* HTML5
* CSS3

## Features Included
* Profile/Hero section with a professional avatar placeholder
* About Me section describing my background
* Skills section utilizing a visual grid layout
* Projects section with placeholder project cards and GitHub links
* Contact section with email and social icons
* Smooth scrolling navigation between sections
* Fully responsive layout adaptable to desktop and mobile screens
