# Temperature Converter Website - Oasis Infobyte SIP Task 3

This is an interactive temperature converter built for the Oasis Infobyte Web Development Internship (Level 1, Task 3).

## Technologies Used
* HTML5
* CSS3 (Flexbox and modern UI design)
* JavaScript (Vanilla JS for DOM manipulation and conversion logic)

## Features Included
* Numeric input field for temperature values
* Dropdown menu to select the source unit (Celsius, Fahrenheit, Kelvin)
* Auto-conversion displaying all output units simultaneously on button click
* Input validation (rejects empty or non-numeric inputs)
* Edge case handling to prevent calculations below Absolute Zero (-273.15°C / -459.67°F / 0 K)
* Clean, centered UI layout
