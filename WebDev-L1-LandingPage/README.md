# Landing Page - Oasis Infobyte SIP Task 1

This is a responsive landing page built for a fictional smartwatch brand ("Nexus") as part of the Oasis Infobyte Web Development Internship (Level 1, Task 1).

## Technologies Used
* HTML5
* CSS3 (Flexbox for responsive layout)

## Features Included
* Sticky navigation bar with links
* Hero section with headline and CTA button
* Two distinct content sections (Features and Testimonials)
* CSS Flexbox for mobile-responsive layout
* Consistent color palette and typography
